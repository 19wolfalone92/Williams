# Как запустить Williams Bot, если у вас нет VPS и домена

## Что нужно купить/создать

Нужен только **VPS**. Домен покупать не обязательно.

### Простой вариант

Создайте небольшой Ubuntu/Debian VPS. Для такого бота достаточно небольшой виртуальной машины; например, DigitalOcean указывает Basic Droplet 1 GB за $6/месяц, а самый маленький 512 MiB — $4/месяц. Цены могут меняться. citeturn1search0

### Возможный бесплатный вариант

Oracle Cloud указывает Always Free ресурсы, включая до 2 OCPU и 12 GB памяти для Ampere A1 в сумме в пределах Always Free лимитов. Однако в регионе может не быть свободной ёмкости. citeturn1search4

## После создания VPS

Нужно только один раз загрузить папку проекта на VPS и выполнить:

```bash
cd Williams_fixed/deploy
./install_no_domain.sh
```

После этого бот работает на VPS 24/7 независимо от телефона.

Телефон может быть выключен, потерять мобильный интернет или вообще быть вне сети. Торговый процесс остаётся на VPS.

Приложение подключается к VPS через HTTPS/WSS. Tailscale Funnel автоматически создаёт публичный HTTPS URL и TLS. citeturn0search2turn0search1

## Самое важное

Телефон — это **панель управления**, а не место, где работает торговый цикл.

```text
Binance
   ↕
VPS 24/7
   ↕
Android APK
```

Это означает, что выключение телефона **не остановит торговлю**.
