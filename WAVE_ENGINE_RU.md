# Multi-Timeframe Wave Engine — Williams Trader 4.12.0

## Назначение

Wave Engine добавляет к существующему Williams Scanner структурный контекст нескольких таймфреймов. Он **не создаёт BUY-сигнал** и не может обойти Risk Engine или state machine Trader.

Архитектура по умолчанию для базового `1h`:

```text
1D  → старшая степень / контекст
4H  → средняя степень / HTF
1H  → рабочая структура
15m → младшая структура / входной контекст
```

Для других базовых ТФ цепочка выбирается автоматически или задаётся `WAVE_TF_CHAIN`.

## Связь с «Торговым хаосом 2»

В загруженной книге фрактал рассматривается как базовая структура волны Эллиотта; движение между восходящим и нисходящим фракталом относится к волне некоторой степени. Книга также требует панорамного взгляда и указывает на использование порядка 140+ баров для Level-2 структуры. В разделе об Alligator состояние вне «пасти» связывается с импульсным движением, а движение около балансирующей структуры — с реактивным/коррекционным состоянием.

Полная авторская методика торговли волнами Эллиотта в самой книге не приведена: книга отсылает к более раннему *Trading Chaos*. Поэтому код ниже не выдаёт свои W1–W5 числа за полный авторский Elliott count.

## Как определяется W1–W5

Номер волны — **структурная оценка**, построенная на подтверждённых Williams-фракталах, чередовании swing-high/swing-low, последовательности повышения/понижения экстремумов и текущем направлении движения. Проверки прогрессии мягкие: они усиливают оценку, но не являются скрытыми жёсткими правилами из отсутствующей книги.

Жёсткие Fibonacci-коэффициенты в Wave Engine не используются.

После подтверждённого пятиволнового импульсного скелета новый ход в обратную сторону маркируется как `A`, а не как повторный W2/W4.

## Вложенные волны

Ключевая логика:

```text
1D  → W5
└── 4H → W3
    └── 1H → W3
        └── 15m → W2
```

`W5` старшего уровня **не является veto**. Если на дочернем таймфрейме обнаруживается согласованная W3, это повышает `nested_w3` / `nested_w3_parent_w5` и добавляет положительную надбавку к Wave Score.

## Wave Score

Wave Score объединяет:

- межтаймфреймовое направление;
- импульсное состояние;
- структурную уверенность;
- качество рабочей волны;
- согласованность направления;
- наличие вложенной W3;
- риск истощения.

В текущем интеграционном слое влияние Wave Score ограничено:

```text
wave_adjustment = clamp((WaveScore - 50) * 0.20, -10, +10)
final_score = clamp(base_score + wave_adjustment, 0, 100)
```

При `WaveScore=50` старый Williams Score не меняется.

## Истощение

W5 повышает `wave_exhaustion_risk`, но не запрещает сделку сама по себе. Дополнительные признаки — AO divergence, слабый импульс и чрезмерно растянутый текущий ход.

## Полный рынок USDT

По умолчанию scanner может получать полный список Binance Spot/USDT через `exchangeInfo`.

```text
SCAN_ALL_USDT=true
SCAN_MAX_SYMBOLS=0
EXCLUDE_LEVERAGED_TOKENS=true
SCAN_WORKERS=4
```

Пустой `AUTO_SCAN_SYMBOLS` / `SCAN_SYMBOLS` означает автоматическое обнаружение. Явный список остаётся поддержан.

Для ограничения нагрузки Wave Engine запускается на всех строгих сигналах и на `WAVE_SCAN_TOP_N` лучших наблюдаемых кандидатов.

## Производительность

Автономный Trader не сканирует весь рынок каждые 20 секунд. Интервал автоматического запуска ограничен `AUTO_SCAN_MIN_INTERVAL_SECONDS` (по умолчанию 90 секунд). Android/REST использует TTL `SCANNER_CACHE_SECONDS` (по умолчанию 30 секунд), чтобы повторное обновление не запускало новый полный скан без необходимости.

## Безопасность

Wave Engine не содержит вызовов BUY/SELL/OCO. Строгий `Candidate.signal` остаётся старым Williams entry condition. Для реального исполнения требуется пройти Trader state machine, Risk Engine и отдельные execution guards.

По умолчанию сохраняются `TESTNET=true`, `ALLOW_LIVE=false`, `DRY_RUN=true`.

## Настройки

См. `.env.example`. Основные параметры:

```text
WAVE_TF_CHAIN=
WAVE_LOOKBACK=220
WAVE_MIN_BARS=140
WAVE_SCAN_TOP_N=12
AUTO_SCAN_SYMBOLS=
SCAN_ALL_USDT=true
SCAN_MAX_SYMBOLS=0
SCAN_WORKERS=4
SCAN_UNIVERSE_CACHE_SECONDS=300
AUTO_SCAN_MIN_INTERVAL_SECONDS=90
SCANNER_CACHE_SECONDS=30
```
