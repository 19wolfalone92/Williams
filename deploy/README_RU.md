# Williams Bot 4.10.0 — VPS 24/7 без покупки домена

Теперь пользователь **не обязан покупать домен**. Для самого простого удалённого режима используется Tailscale Funnel: он выдаёт HTTPS-адрес вида `https://имя-устройства.имя-tailnet.ts.net` и автоматически обслуживает TLS. Официальная документация Tailscale подтверждает, что Funnel может публиковать локальный сервис в интернет через HTTPS и автоматически выдавать TLS-сертификат.

## Что всё равно нужно человеку

Полностью без внешнего аккаунта VPS не существует: сервер должен где-то физически работать. Самый простой вариант — создать Linux VPS у облачного провайдера. Например, у DigitalOcean есть Droplet от $4/месяц, а у Oracle Cloud есть Always Free ресурсы, включая Arm VM в пределах бесплатных лимитов; доступность Oracle зависит от региона/ресурсов. 

После создания VPS всё остальное максимально автоматизировано.

## Вариант A — без домена (рекомендуется для первого запуска)

1. Создайте Ubuntu/Debian VPS.
2. Установите/загрузите проект на VPS.
3. Выполните:

```bash
cd Williams_fixed/deploy
./install_no_domain.sh
```

4. Если Tailscale попросит авторизацию, откройте показанную ссылку на телефоне и войдите в свой Tailscale-аккаунт. Либо заранее создайте одноразовый auth key и задайте `TS_AUTH_KEY` перед запуском. Tailscale официально поддерживает auth keys для автоматической регистрации Linux-серверов без браузерного входа.
5. Скрипт сам:
   - установит Docker;
   - установит Tailscale;
   - создаст Mobile API Token;
   - запустит backend;
   - включит автоматический restart;
   - включит HTTPS Funnel;
   - создаст постоянное хранилище;
   - покажет URL backend;
   - сохранит URL и token в `deploy/credentials/mobile_connection.txt`.

6. В APK вводятся только URL и Mobile API Token.
7. Binance API Key/Secret вводятся один раз в APK и передаются на VPS. На телефоне Secret не хранится.

## Вариант B — свой домен

Можно использовать старый `install_vps.sh`: он ставит Caddy и автоматически получает TLS-сертификат для вашего домена.

## Безопасность

- `TESTNET=true` по умолчанию.
- `ALLOW_LIVE=false` по умолчанию.
- Backend привязан к localhost VPS; наружу его публикует Funnel/Caddy.
- Все мобильные API-запросы требуют Bearer token.
- Binance credentials шифруются на VPS.
- Не публикуйте `deploy/.env` и `deploy/credentials/`.
- Для 24/7 сервера желательно использовать Tailscale auth key с минимальными правами и ограниченным сроком; Tailscale предупреждает, что auth keys нужно хранить как секреты.

## Важное ограничение

Tailscale Funnel публичен для интернета. Поэтому приложение всё равно обязано использовать сильный Mobile API Token. Для production можно перейти на собственный домен + Caddy и дополнительно ограничить доступ.
