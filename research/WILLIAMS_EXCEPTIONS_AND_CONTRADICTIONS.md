# Исключения, противоречия и открытые ограничения

| ID | Доказательство | Следствие |
|---|---|---|
| AO midpoint | TC2 EN155, fig10.1 на оригинальном изображении печатает (H-L)/2 | Это половина диапазона, не середина. Appendix3 EN247 явно задаёт (H+L)/2, SMA5-SMA34: противоречие разрешено по авторскому коду того же издания, сохранён median |
| Lips2/3 | NTD RU36, fig3.4 против основной спецификации той же страницы | Не ошибка OCR. Английская NTD отсутствует;3 сохраняется как явно выбранная реализация, конфликт открыт |
| Большой WM1 | TC2 EN160, fig10.7 | Один большой бар способен создавать угол; требование нескольких внешних баров — численный proxy, не авторский универсальный запрет |
| WM2 задержка | EN158-159, fig10.5 | Шесть баров после WM1 встречаются в примере;2-4 не абсолютный срок |
| WM1 не всегда | EN148-149, fig9.13 | Нельзя выдумывать divergent bar на любом историческом экстремуме |
| Неудачный бар после прибыли | EN147, fig9.11 | Последующий прибыльный разворот не делает невалидный WM1 валидным |
| Порядок мудрецов | EN172 fig11.10; EN177/180 | WM3/WM2 могут быть первыми; не создавать жёсткий автомат1→2→3 |
| STOP варианты | EN177-178 | Base/signal-bar и3-5-bar упомянуты по-разному; выбранный вариант должен быть явным |
| Ранний выход | EN179 fig12.2 | Правильный3-bar STOP может завершить кампанию до окончания старшего тренда |
| MFI equality | TC1 RU43-45; строгие четыре комбинации | Равенство не снижение, исправлено в фундаментальном классификаторе |
| Криптообъём | TC1 RU40-42; Binance kline fields | Trade count/base volume не равны исходным ценовым тикам; proxy остаётся proxy |
| Десять/пятнадцать | Текущее задание против фактического transport/scanner15 | Требуется отдельная миграция NEW risk без потери legacy STOP/позиции; пока открыто |
