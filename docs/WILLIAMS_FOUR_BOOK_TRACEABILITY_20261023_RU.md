## Несмешиваемые правила

1. TC1 **5** сигналов окончания младшего пяти-волнового движения != Course **4** признака в третьем уровне. MFI divergence != 5/34 AO divergence. Два индикационных профиля не могут повышать друг другу confidence без независимого proof.
2. Книжные стоп-развороты и частичные выходы (особенно Course) существуют. Они не дают права закрыть прибыльный SHORT по неопробованному, неподтверждённому WM1 LONG. Для реальных сделок необходимы сигнал, фактический price trigger, состояние кампании, защита и биржевая сверка.
3. AO пересёк ноль в W4 — только минимальный критерий. Текущая свеча W4 не обязательно завершилась. Если нет 100–140 баров, возможно искать аналитическую детализацию меньшего ТФ, **не использовать их в качестве дополнительного условия входа по M15**.
4. Фрактал t+2 подтверждается только после двух закрытых правых баров; смещённые линии Alligator должны использовать рассчитанные фактические SMMA, не экстраполироваться.
5. Никаких действий по Binance со стороны модуля наблюдений волн; никакой обещанной «100% точности» без out-of-sample исторического прогона и исполнительной приёмки.

## Невыполненное перед полным приёмочным сертификатом

- Постраничная визуальная сверка всех 122 PDF-страниц сканированного Course, всех графиков TC1/NTD/TC2.
- Размеченный трейдером корпус реальных закрытых свечей и соответствующих графических эталонов (ангуляция, WM1–3, W2/W4/W5, divergence, invalidation).
- Walk-forward 15 инструментов без утечки будущего, комиссии, спреды, проскальзывание, ликвидность, частичные исполнения.
- Binance Futures Demo E2E: восстановление после reboot, loss of Wi-Fi, API-reject, stop cancellation, double order, no stop, filled-but-unprotected exposure.
- Source ownership TC2/NTD/Course, защита capital, подтверждение exact-HEAD APK. Держать торговый live gateway изолированным от несертифицированных модулей.
