# Williams Bot 2.1 — почему BTC/SOL/DOGE закрылись по SL и изменение добровольного trailing

25 октября 2026, исследование файла `Williams_Diagnostics.zip` и кода TC2.

## Наблюдения Binance

По журналу `ALGO_UPDATE TRIGGERED`:
- DOGEUSDT LONG, стоп 0.07687, цена исполнения 0.07686, полный нетто-результат около -0.9733 USDT;
- BTCUSDT LONG, стоп 80524.7, исполнение 80504.6, нетто около -0.419 USDT;
- SOLUSDT LONG, стоп 101.71, исполнение 101.70, нетто около -0.061 USDT.

Закрытия — исполнение существующих Binance STOP, а не непосредственная команда закрыть по противоположному WM. **Могло ли движение впоследствии пойти в направлении первоначальной позиции, этот архив сам по себе не доказывает.**

## Причина повышенной агрессивности

`planWilliamsCampaignStop()` ранее разрешал `TC2_LAST_5_CLOSED_BARS`, когда **лишь последний из пяти баров закрылся после входа**. Остальные четыре могли относиться к рынку ДО создания данной кампании. Для молодого тренда это может слишком рано подтягивать SL. Фрактальный вариант `CONFIRMED_H1_FRACTAL` уже требует причинно подтверждённый pivot после входа.

Также в продакшн-вызовах отсутствовал H4 контекст перед принятием добровольного H1 trailing: неопределённая фаза W3/W4/W5 или явные противодвижения старшего H4 не получали отдельного объяснения в журнале.

## Консервативный фильтр (ИНЖЕНЕРНАЯ защита, а не дословное правило книги)

В **двух** производственных путях добровольного TC2 сопровождения (родная кампания и авторизованная отдельная позиция) добавлен `reviewWilliamsTc2StopTightening()`:
1. Берутся действительные свежие **закрытые H1 и H4** свечи из биржевого источника (без lookahead, 40+ свечей); если H4 отсутствует, прежний Binance стоп не изменяется.
2. Кандидат строится только по существующему исходному правилу TC2 5 закрытых H1 баров или t+2 фракталу. **5-барное подтягивание требует пять полноценных H1 свечей после биржевого открытия позиции**, а не четыре бара из прошлого.
3. Для варианта последних пяти баров ярко выраженное противодвижение H4 (LONG: снижение и минимума, и close; SHORT: рост и максимума, и close) откладывает добровольное подтягивание. Это ценовой фильтр, **не автоматическая разметка Эллиотта**.
4. Кандидат слишком близко к mark относительно половины медианного H1 диапазона за 12 закрытых часов (с защитным потолком 0,15% цены) откладывается; существующий STOP сохраняется. Нет автоматического переноса стопа дальше от рынка.
5. Записываются источник правила, точные open timestamps и OHLC/H1(5) H4(2), альтернативные H1/H4 *гипотезы* волн (не исполнительное доказательство), рассчитанные старый/новый возможный нетто-результат **на единицу позиции** с моделью комиссии/проскальзывания; финансирование, ликвидность и реальные будущие fills не известны.
6. При отказе публикуется диагностическое событие `TC2_STOP_REVIEW_DEFERRED` с причиной, при фактически подтверждённом переносе — `PROTECTION_TRAILED` с доказательствами. Binance coordinator продолжает требовать уникально подтверждённый ранее стоп и заменяет защиту только по безопасному протоколу; предлагаемое улучшение никогда не закрывает позицию само по себе.
7. Разметка волн H1/H4 логируется **как гипотеза, не как сертификат**. H4 с противным движением — только предупреждение и запрет добровольного ускоренного 5-bar tightening; надёжность и инвестиционная полезность этой эвристики должны проверяться на независимой истории.

## Ограничения

Прогнозировать дальнейшую цену и достичь 100% сделок без убытков невозможно. Слишком далеко стоящий стоп увеличивает риск: прежний защищающий Binance STOP **сохраняется на том же уровне** при недостаточном доказательстве, поэтому его риск остаётся. Нельзя делать вывод о качестве улучшения по трём отдельным наблюдениям — нужен независимый тест без выбора лучших исходов с будущих свечей.
