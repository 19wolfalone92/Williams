# Историческая проверка вложенных волн — 4.30.1

Проверка продолжает выпущенную main 4.30.0 (`efee34ea`). Изменения проверяются на исходных публичных свечах Binance USDⓈ-M, без отправки торговых заявок.

## Данные и воспроизведение

Выборка: 120 000 закрытых M15-свечей, по 12 000 для BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT, XRPUSDT, DOGEUSDT, ADAUSDT, LINKUSDT, AVAXUSDT, LTCUSDT. Период: 12 сентября 2024 — 15 января 2025 UTC, правая граница не включается. D1/H6/H1 агрегируются исключительно из полных групп этих же M15-свечей. Пропуски, повторные времена, незакрытые свечи и недопустимые OHLCV не разрешены. Объём сохраняется как объём Binance, а не выдаётся за книжный tick volume.

```bash
python tools/audit_historical_wave_subdivisions.py \
  --data-dir /absolute/path/to/raw \
  --output /absolute/path/to/wave_audit.json
python -m pytest -q
python ci_release_gate.py
CI=true python full_safety_audit.py
```

Исходные 80 страниц данных, их SHA-256, полный JSON результата и примеры подтверждённых внутренних структур входят в отдельный пакет доказательств. Скрипт не обращается к аккаунту и воспроизводится без сети.

## Что проверяется

1. Для каждого исторического H1-среза используются только известные к нему экстремумы. Независимый расчёт хранит раздельные события подтверждения high/low, учитывает равные экстремумы и двусторонние внешние бары.
2. Ежедневные срезы сравнивают все производственные фрактальные опорные точки с независимым расчётом по OHLC. Затем строится действительный граф D1 → H6 → H1 → M15.
3. Каждый кандидат получает проверку реальных младших конечных точек: совпадение цены, положение внутри старшей свечи, время подтверждения, число участков и геометрия каждого участка. Название фигуры само по себе не подтверждает её внутреннее строение.
4. При положительном результате удаление конечной точки и перенос подтверждений в будущее обязаны вернуть `UNRESOLVED`.
5. Дописывание незакрытой будущей свечи с недопустимыми значениями не должно менять текущий граф. Отмена сценария по последующей цене должна иметь реальное пересечение после экстремума.
6. Реальные исторические случаи перенесены в общий JSON контракт Android/Python, включая зеркальные направления, потерю конечных точек и подтверждения из будущего.

## Исправления по результатам проверки

| Ошибка | Исправление |
|---|---|
| Обычная плоскость объявлялась при C, не достигшей A | Отдельная незавершённая/усечённая альтернатива; окончание C остаётся неподтверждённым |
| Противоположный экстремум исходной свечи считался последующим пересечением | Начало наблюдения определяется по последнему совпавшему экстремуму на самом младшем полностью доступном масштабе. Участок внутри этой свечи не получает выдуманного порядка high/low |
| Возможная диагональ затем отменялась по обычному запрету перекрытия W1/W4 | Для неисполняемой диагональной альтернативы сохраняется граница начала W3. Обычный импульс продолжает использовать свою границу |
| Зональное NTD-событие истекало в момент закрытия сигнальной свечи | Срок действия включает 90 секунд после реального закрытия; фактическая цена и ограничение отклонения проверяются перед отправкой |
| Несколько измерений NTD на одном баре подавлялись общим временем последнего сигнала | Разные принадлежащие кампании формирования рассматриваются отдельно; исходный вход и уже принятые clientId повторно не используются. Одновременно допускается одна ожидающая доливка, общий риск сохраняется |
| Просроченное MARKET-событие могло заслонять действительные STOP-сигналы | События фильтруются до выбора; свежее короткое событие получает приоритет |
| Противоположная зона NTD игнорировалась как выход, поскольку не является STOP_ENTRY | Закрытое событие после открытия позиции разрешает уменьшение риска в ограниченном окне восстановления. Это не разрешает исторический MARKET-вход или автоматический разворот |
| Python применял входной Course momentum-фильтр к противоположному выходу | Проверка сигнала выхода разделена с допуском нового риска, как в Android |

Исторический пример первой ошибки: BTCUSDT H1, 16 ноября 2024, `as_of=1731754800000`. A завершалась на 90 900, B — 91 849,8, предполагаемая C — 91 076,2. C не достигла A; название обычной плоскости было необоснованным. Исходные подтверждённые точки сохранены в `williams_historical_wave_cases.json`.

## Практический смысл результатов

Подтверждённая геометрия — проверяемое свойство этих свечей и выбранного масштаба, а не гарантия единственно верного волнового счёта. Статусы `ALTERNATIVE` и `UNRESOLVED` сохраняются; сложные структуры не получают права размещать ордера. Вход H1, направление, владение позицией, защита Binance, сессия, плечо и бюджет риска проверяются отдельно.

Полный JSON показывает как положительные внутренние доказательства, так и отклонённые или не встретившиеся конфигурации. Отсутствие положительного примера на выбранном периоде не превращается в заявление о доказанной исторической точности такого класса. Здесь не рассчитывается прибыльность и не выполняется ручная эталонная разметка всей выборки.

Приёмка на физическом телефоне с аутентифицированными событиями Futures Demo остаётся самостоятельной проверкой установленного APK.
