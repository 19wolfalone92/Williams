# Williams Bot 2.1 — TC2 сопровождение: контроль полного аудита (25.10.2026)

Основа: draft PR #150, коммит `c775d7f6490276f5ebc976f5a828d801e0a621f6`.
Данный набор изменений **не означает приёмку Binance Demo**, подтверждение прибыльности или 100%-ную эквивалентность четырём книгам Вильямса.

## Реализовано в этом изменении

1. **Полный структурированный журнал переносов**: каждое предлагаемое добровольное подтягивание TC2 сохраняется *до* отправки в Binance через `WILLIAMS_STOP_TRAIL_DECISION_V1`, привязано к `campaign_id`, стороне, версии исходного кода, полной `decision_evidence` (OHLC, H1/H4, фракталы, wave hypothesis, old/new stop, правило). Ошибка обязательной записи запрещает **добровольный перенос**, но не отменяет действующий биржевой стоп.
2. **Подтверждение Binance отдельно от предложения**: после ответа записывается `EXCHANGE_RESPONSE_OK` либо `EXCHANGE_NOT_CONFIRMED` с оригинальными полями ответа. Запрос в неопределённом состоянии **не повторяется ради аудита**. Наличие предоперационного `PROPOSED_BEFORE_MUTATION` без последующего ответа — повод для сверки Binance, но **не доказательство**, что стоп был заменён.
3. **Разные типы данных**: события `COCKPIT_*` ограничиваются для UI, полный `WILLIAMS_STOP_TRAIL_DECISION_V1` сохраняется в таблице `events` SQLite без ограничения 1600 символов; диагностика `stop_trail_decisions_full.json` содержит последние 300 полных событий, а не обрезанные строки. Полная база на телефоне — источник для старых кампаний, не 300 последних из ZIP.
4. **Экономика позиции**: для принадлежащей боту позиции общее количество берётся из текущей подписанной биржевой позиции, а средняя цена — из Binance. Логируются `old_estimated_net_campaign_usdt`, `new_estimated_net_campaign_usdt` и их изменение с допущениями по издержкам. **Это приблизительная оценка**, она не заменяет журнал реальных добавлений, комиссий, funding и проскальзывания; непроверенный объём подключённой внешней позиции не получает фальшивую сертификацию.
5. **Регрессии**: проверка сериализации события длиной >1600 символов, результатов биржи, валидации кампании, длинных/коротких позиций и количества.

## Разбор трёх инцидентов — подтверждено и не подтверждено

| Пара | Наблюдённый старый → новый SL | Факт по известной диагностике | Что пока невозможно доказать |
| --- | --- | --- | --- |
| DOGEUSDT | 0.07636 → 0.07687 | Закрытие на Binance STOP после подтягивания, не по обратному мудрецу | Был ли новый SL запрещён текущим H1/H4 именно на момент решения |
| BTCUSDT | 80094 → 80524.7 | Подтягивание и последующее STOP-исполнение | Как отработали бы старые/новые правила при тех же закрытых H1/H4 |
| SOLUSDT | 98.74 → 101.71 | Подтягивание и последующее STOP-исполнение | Изменение результата при сохранении старого стопа, включая дальнейшую цену |

До реального сравнительного `old/new` replay необходимы **полные OHLC-истории, точные timestamps каждого решения и исполнения, объёмы всех добавлений, Binance signed STOP receipts**. Одних стоп-цен и итогового PnL недостаточно: восстанавливать неизвестные свечи запрещено. Фактическое продолжение движения рынка также нельзя подменять знанием из будущего.
