## Исправленное поведение

1. Завершённый пятиходовый импульс остаётся историческим свидетельством при глубокой последующей A-коррекции. Старый экстремум W1 больше не стирает завершённую W5. Для незавершённой W5 нарушение структуры, включая хвост свечи при удержавшемся закрытии, продолжает отменять гипотезу. То же разграничение действует для исторической альтернативы диагонали.
2. Python использует тот же терминальный Squat, что Android: проверяются три наиболее экстремальных ценовых бара пятой волны. Соседство с последним экстремумом само по себе недостаточно. Биржевой base volume остаётся обозначенным приближением исходного tick volume.
3. Устаревшее или недоступное чтение графика больше не показывается как свежий контекст в Android narrative. Python сохраняет запрошенную цепочку D1/H6/H4/H1/M15 при сериализации вместо возврата старого четырёхмасштабного списка.
4. `WilliamsWaveInterpretation.kt` / `williams_wave_interpretation.py` различают младшую коррекцию внутри импульса, продолжение, младший импульс внутри старшей коррекции, встречный импульс без отмены старшего счёта и кандидат старшего разворота после наблюдаемого нарушения собственной структуры. Разные допустимые объяснения остаются `ALTERNATIVES`.

## Продолжение: проверка нескольких степеней и книжный checklist (Course PDF59–60)

Из оригинальных **рисунков** Course PDF59 («IMPULSE WAVE CHECK LIST») и PDF60 («CORRECTIVE WAVE CHECK LIST») выделены ветви подсчёта. Проверка основана на просмотре сканов, а не на слепом OCR. В частности, три внутренних хода при предполагаемой W1 означают возможность незавершённой коррекции, а три хода при W3 требуют пересмотра счёта. Для W2/W4 различаются кандидаты боковой (3) и резкой (5) коррекции; три хода в W5 не означают автоматически завершённый обычный импульс. Термин «три/пять» означает обнаруженные **подтверждённые экстремумы реального младшего таймфрейма**, а не будущее идеальное число разметки.

В `williams_wave_subdivisions.py` и `WilliamsRecursiveWaveDegree.kt` добавлен read-only, ограниченный по числу узлов рекурсивный проверяющий механизм. Он не угадывает отсутствующие бары: для каждого родительского сегмента требуется уникальное соответствие его крайних точек фактическим подтверждённым pivot младшего масштаба, правильные 5–3–5 / 3–3–5 / 5–3–5–3–5 и причинное `known_at <= as_of`. При неоднозначности, пропуске нужного масштаба, незавершённости подтверждения или исчерпании вычислительного бюджета ответ `PARTIAL_PRICE_GRAMMAR` либо `UNRESOLVED`. Ложного «заполнения» структуры не производится. Глубина ограничена 1–3 вложенными переходами, бюджет — 64 узла на гипотезу.

Код подключён к построению иерархии: в `complex_wave_patterns[].recursive_proof` записываются фактический путь масштабов, проверенная геометрия, ветви checklist и причины сомнений. Kotlin и Python используют общий числовой JSON-контракт `williams_recursive_degree_course_contract.json`; он содержит **синтетические проверочные крайние случаи**, а не восстановленные OHLC из рисунка Course. Реальная причинная историческая проверка должна отдельно использовать сохранённые биржевые свечи; наличие корректной синтетической структуры не доказывает способность бота автоматически размечать все графики.

**Ограничения:** даже `OBSERVED_DEPTH_PRICE_GRAMMAR_CONFIRMED` доказывает только структуру цены на запрошенных наблюдаемых масштабах. Это не независимое подтверждение единственной гипотезы Эллиотта, корректности вероятностного прогноза, всей истории и тем более прибыльности. Нельзя давать таким доказательствам полномочия на вход, разворот, перенос или отмену стопа. `unique_elliott_genealogy_proven=false`; `can_place_orders=false`, `can_close=false`, `can_reverse=false`. Полная ручная оцифровка книжных графиков, внешние видеоуроки Course и испытания телефона/Binance Demo остаются открыты.


### Дополнительная проверка именно рисунка Course PDF60

Просмотренный скан «CORRECTION WAVE CHECK LIST (BULL MARKET EXAMPLE)» добавляет отдельные причинные развилки. A: три хода вниз — коррекция ещё не подтверждена, пять — резкое начало коррекции, но возможно лишь одно звено более крупной боковой структуры. Следующая структура 1/X: три хода — вероятность сложной коррекции, пять — возможное завершение коррекции и начало W1 (не доказанное само по себе). Ранее для пяти звеньев треугольника использовались ярлыки W1–W5; теперь они правильно именуются A–E и не разрешают торговлю.
