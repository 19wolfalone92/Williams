# Williams 4.51.0 — удобный экран, ориентация и проверяемая защита TC2

Дата: 20.10.2026, Europe/Minsk.

## Что исправлено по присланному экрану

Причины тесноты были в нескольких вложенных отступах, горизонтальном ряду слоёв и размещении последней свечи точно на правой границе Canvas. Подписи Мудрецов начинались у этой границы и обрезались.

- Уменьшены отступы страниц и карточек; график использует больше доступной ширины.
- Цена вынесена на отдельную правую шкалу, метки ограничены областью свечей. Свечи располагаются по центрам ячеек; крайние свечи находятся внутри графика.
- Значения входа/SL/заявки дополнительно показаны переносимой легендой под графиком. Если строка Canvas физически не помещается при огромном шрифте, она не рисуется обрезанной; полные значения остаются в обычном тексте.
- Исправлено округление малых цен: график и карточка кампании сохраняют до 8 десятичных знаков; неизвестные цены не подменяются нулём.
- Слои открываются отдельной кнопкой и переносятся на строки. Челюсти, зубы и губы подписаны по-русски.
- Добавлены кнопки масштаба, переход к последним свечам, горизонтальное перемещение и развернутый график.
- Вертикальный жест уступает прокрутке страницы; выделение свечи не срабатывает при нажатии на ценовую шкалу.
- AO/AC выровнены с областью свечей; цвет первого видимого столбца учитывает предыдущий бар за пределами окна.
- Маркеры исторических сделок используют действительный интервал просмотра, включая календарные месяцы.
- Общие поля карточек на узкой панели ставят значение под подписью. На широкой панели используются две ограниченные колонки.
- Упрощена верхняя панель. В горизонтальной ориентации навигация располагается сбоку; в вертикальной — снизу.
- Меню поворота: авто по настройке телефона, горизонтально, вертикально. Выбор сохраняется.
- Пара, интервал, историческая сделка и настройки графика используют сохраняемое состояние. Страница остаётся в одной позиции композиции при смене раскладки.

## Подтверждённые дефекты торговой цепочки

1. Ранее основной цикл запрещал TC2 market-close, но Native coordinator принимал произвольный STRATEGY_EXIT. Теперь конечный closePosition проверяет закреплённую редакцию ДО отмены доливок, сетевых запросов и записи EXIT intent. Для TC2 обычный рыночный выход отклоняется без биржевых изменений и без глобальной паузы.
2. Тот же запрет добавлен в Python _exit_market до отмены доливок/чтения позиции. Ручное закрытие и явный путь аварийного уменьшения риска сохраняют прежние проверки биржевой позиции/объёма. Аварийный путь отмечен отдельным аргументом и происхождением.
3. 3/5 баров не должны строиться из разорванной H1-последовательности. Обе реализации теперь отказываются предлагать перенос при пропуске часа. Подтверждённый прежний SL остаётся действующим.
4. Python разрешал барный перенос при неизвестном времени открытия, тогда как Android его запрещал. Python приведён к той же консервативной политике: сначала установить время фактического открытия.
5. Последний подтверждённый перенос сохраняет основание, прежнюю/новую цену, время, владельца и client ID. В компактной диагностике ID удалён, полная запись остаётся в журнале. Незавершённая попытка не выдаётся за подтверждённый перенос.
6. Карточка кампании и паспорт показывают основание последнего подтверждённого переноса; обычный TC2 выход и ручные/аварийные действия различаются явно.

Замена защиты сохраняет действующий порядок: сверка владельца/позиции, создание и подтверждение нового стопа, отмена прежнего, повторная проверка единственного стопа. Риск не расширяется. Аварийная защита от фактического нарушения liquidation/risk cap не отключена.

## Проверки и пределы результата

Новые исполняемые проверки:
- геометрия крайних свечей, шкалы и меток, выбор свечи, границы масштаба/истории, малые цены и календарные интервалы;
- production Native coordinator с подписывающим адаптером и моделируемой биржей: LONG/SHORT, запрет TC2 до любого запроса, сохранение защиты, явный kill, подтверждённое основание переноса;
- Python production _exit_market: отказ до отмены заявки/чтения позиции; разрешённые пути продолжают существующий preflight;
- обе реализации 3/5 стопа: неизвестное время открытия и пропуски H1.

Проверки выполняет GitHub Actions; exact-HEAD, main, результаты тестов, APK и SHA-256 приводятся в PR выпуска. В этой сессии командная среда и Android-эмулятор недоступны. Скриншот пользователя изучен непосредственно в сообщении; отрисовка изменённого APK на устройстве ещё не проверена.

Для Course повторно запрошены страницы PDF 89–90; доступны указатели изображений без читаемого текста, но их пиксели не удалось получить в доступном окружении. Полный визуальный аудит Course/всех книжных рисунков НЕ выполнен. Для него нельзя назначить 100% соответствие.

Остаются: фактическая визуальная приёмка на телефоне с крупным шрифтом/жестами/поворотом, реальные Demo fills → SL → trail → stop-fill → restart, многодневная автономность и оценка точности сложных волн. NTD/Course продолжают наблюдать; новая архивная волновая модель не получает права торговать.
