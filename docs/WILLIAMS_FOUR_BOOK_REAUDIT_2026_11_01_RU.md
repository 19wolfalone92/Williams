## Реальная исполнительная совместимость

**Согласованная пользователем архитектура:** в `WilliamsExecutionPolicy.kt`
константа `TC2_ONLY_NEW_EXPOSURE_V3`. **Только TC2** открывает реальные
новые позиции Binance Futures. NTD и Course остаются независимыми
источниками исследования и ведут собственный **условный бумажный
журнал** входов, стопов и наблюдений без Binance-ордеров. Ранее
существовавшие позиции других источников не теряют защитного
сопровождения. Это **желательное** разделение LIVE/OBSERVE, а не
расхождение с пользовательским заданием. Полное книжное сравнение
NTD и Course всё равно требует воссоздать и независимо проверить
их системы в исследовательском журнале, не на реальном аккаунте.
См. `docs/WILLIAMS_TC2_LIVE_NTD_COURSE_PAPER_OBSERVER_2026_11_01_RU.md`.

**Специфика биржи против книг:** stop на Binance имеет фильтры шагов,
ликвидационную маржу и специфику экстренной защиты; ограничение
суточного риска 3%, выбранный leverage, запрет незащищённого входа,
средний объём вместо авторского tick-volume и H1-only согласованное
пользователем исполнение — инженерная адаптация, не точная
историческая торговля из книг. Невозможно одновременно считать
эти дополнительные ограничения и алгоритмы строго буквальным
повторением всех книжных правил.

## Дополнение 02.11.2026 — TC2: два устранённых расхождения в проверке сигнала

**TC2 PDF122, рис. 9.1/9.2.** Бычий бар должен закрыться **строго в верхней половине**, медвежий — **строго в нижней**. Равенство close == (high+low)/2 не удовлетворяет ни одному условию. Ранее Kotlin допускал равенство в WM1 (>=, <=); теперь использует строгие >, <. Python теперь перепроверяет реальные OHLC, предыдущий экстремум, и соответствующую половину, не доверяя только флагу bullish_reversal_bar / bearish_reversal_bar. Ангулляция и направление AO остаются отдельными обязательными проверками.

**TC2 PDF137–139, рис. 10.3/10.5.** WM2 требует три последовательных изменения AO в сторону входа; trigger ставится за ценовым баром, соответствующим **третьему** AO. Python теперь проверяет исходные AO для всех баров последовательности, а не доверяет только заранее рассчитанному ao_green_streak / ao_red_streak. Нет данных AO, одинаковые значения или NaN не являются подтверждением.

Добавлены проверочные случаи LONG/SHORT с точной серединой диапазона, подменённым флагом WM1, подменённой последовательностью WM2, равными/NaN значениями AO. Статусы 49 зарегистрированных книжных правил НЕ объявлены полными: требуется независимая разметка исходных рисунков, исторические свечи, кросс-языковое сопоставление, реальные испытания Android / Binance Demo.

Исполнение новых реальных ордеров остаётся только TC2; TC1/NTD/Course ведут исключительно наблюдения. Новые проверки не отменяют SL, риск, леверидж и не разрешают дополнительные биржевые действия.
