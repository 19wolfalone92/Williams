# Williams 4.57.0 — объединение веток 23 октября 2026

Проверены все 71 исходная ветка `19wolfalone92/Williams`. Основой служит проверенный
4.56.1 (`6f6de1d8137a099ce7715c13775d9b528a85e3d0`). Исходный main
`27e4053134494648a62c60bd1a15d3d20b6e038f` сохранён в
`backup/main-before-consolidation-20261023`. Ветки не удаляются. Williams-AI не затрагивается.

## Что означает объединение

33 головы уже входят в 4.56.1. 38 голов расходятся с ней; четыре из них входят
в другие расходящиеся ветки. Оставшиеся 34 головы включены в историю интеграции.
Из них 16 — независимые ветки последних исправлений, 18 — более ранние
альтернативные архитектуры/аудиты. Историческое объединение не означает
включение каждого устаревшего алгоритма в действующий движок.

Совместимые изменения перенесены; пересекающиеся устаревшие исполнения заменены
действующими контрактами 4.56.1. Полный реестр голов и решений находится в
`branch_consolidation_20261023.json`. Любой исторический вариант доступен по
сохранённому SHA; снимки веток и незавершённые аудиты не выдаются за приёмку.

## Перенесённые независимые изменения

- Настоящий локальный снимок D1/H6/H4/H1/M15 до даты наблюдения; отсутствие,
  пропуск, устаревание истории и отсутствие анализа различаются.
- В карточке решения показываются положение цены относительно пасти,
  фаза Аллигатора, знак и динамика AO/AC, зона и известный смещённый хвост
  Аллигатора. Хвост использует уже рассчитанные SMMA, не будущие цены.
- Независимые текущие гипотезы каждого ТФ сохранены из более новой модели;
  номер/степень волны и вероятность не выдаются за установленный факт.
- Произвольная цепочка анализа проверяет каждый запрошенный ТФ; H4 нельзя
  пропустить при отображении полной пятиуровневой цепочки.
- Чтение подписанного учёта для восстановления суточной базы независимо от
  синхронизации private stream; это не снимает паузу и не разрешает заявки.
  Только свежий подтверждённый нулевой fill ожидающего входа допускается как
  отсутствие экспозиции, вместе с отдельной проверкой фактической FLAT-позиции.
- Непробитый NTD AC-сигнал отменяется после смены цвета; последующее восстановление
  требует новой формации. NTD продолжает работать только в наблюдении.
- Перенесены недостающие русские подписи; Android и Python API имеют номер
  4.57.0, контролируемый единым release gate и файлом VERSION.

## Решения по конфликтам исполнения

- Последний NativeFuturesCampaignCoordinator и адаптер сохранены целиком:
  подписанная идентичность STOP, временная защита при замене, UNKNOWN/recovery,
  контроль владельца и финальный запрет убыточного встречного TC2-выхода.
- Старый дополнительный путь аварийного закрытия при неподтверждённом запросе
  STOP из ветки 4.51.5 не заменяет более новую политику доказательства отсутствия.
- M15 не возвращается как обязательное подтверждение H1. Произвольный 1R
  безубыток остаётся отключённым. NTD/Course не получают новых торговых полномочий.
- Старые Spot/V2 writers, независимые альтернативные Futures engines,
  прежние схемы credential storage и source-text проверки старых DTO остаются
  в истории, без подключения второго исполнителя к текущему Android runtime.

## Границы готовности

Эта консолидация не закрывает оставшиеся книжные эталоны WM1, сложные вложенные
волны, завершение полного replay, новые live-кампании NTD/Course и физическую
Binance Futures Demo приёмку перезагрузки/FI-01…FI-12. Автоматический обратный
вход после закрытия не включается. Конфигурация счёта и биржевые заявки не меняются.

## Проверка

Требуются release gate, проверка Python undefined names/syntax, полный pytest,
Android unit tests, lint и APK build на точном интеграционном коммите. Успешная
сборка подтверждает интеграцию кода; устройство и действующее состояние Binance
оцениваются отдельно. Главная ветка обновляется после успешного CI.
