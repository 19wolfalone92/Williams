## Подтверждённое существенное расхождение, исправленное в этом PR

Раньше `StandaloneRuntime` и `NativeFuturesCampaignCoordinator.closePosition` **запрещали** TC2-закрытие по полностью подтверждённому противоположному сигналу, если mark или bid/ask не обеспечивали положительный результат после резерва 0,35%. Это свойство проекта, а не общее правило TC2. В книге (PDF p.154,155,158) контрсигнал служит развороту, не требуется положительный нереализованный PnL текущего владельца. Отрицательный результат может быть штатной частью закрытия неверного направления.

Правка:
- TC2: разрешён выход по подтверждённому **исполненному** противоположному сигналу и с убытком.
- NTD/Course: старый ограничитель не менялся; эти профили всё равно не исполняют новые сделки.
- Любая неоднозначность signed Binance данных, ownership, quantity, pending status, CLOSED-H1 provenance, времени сигнала или CONTRACT crossing — **блокировка**. Защитный биржевой STOP не удаляется до окончательно подтверждённого закрытия.
- Отдельный тест должен доказать обе стороны LONG/SHORT и запрет закрытия без действительного opposite trigger.

## Важные неснятые расхождения (не «найденные баги», пока не доказаны)

1. WM1 **ангуляция**: книга описывает геометрический рисунок, а приложение использует расстояния и наклоны. Нужен независимый экспертный gold set по рисункам 9.1–9.13, с классами «параллельно», «прокалывает пасть», «верная ангуляция», «неопределённость».
2. **Вложенные волны, сложные коррекции:** 4-я волна и нуль AO, степень вложенности, альтернативные разметки. Без слепого набора экспертных графиков нельзя давать процент точности или считать любой proxy полностью книжным.
3. **3/5 баров:** автор допускает выбор в зависимости от характера рынка/трейдера; автоматическая политика по умолчанию выбирает один вариант с дополнительными защитными veto. Нужно отдельно пометить режим и сравнивать два *гипотетических* стопа без рискового переключения в продуктивном исполнении.
4. **Реверс 2×:** прямой встречный объём из книги нельзя безопасно имитировать без обеспечения защиты и полного reconciliation на Binance. Отдельная flat-последовательность — осознанное отличие.
5. **Точность других трёх источников:** все сравнения по ним *не должны* менять исполняемый TC2. Сохранять shadow записи точек входа/выхода с источником/страницей и причинно корректным знанием свечей.
6. **Course scan:** не требовать «100%» по неоцифрованным страницам, пока изображения и схемы не проверены с независимым эталоном.

## Условия доказательного приёмочного теста

- 100+ заранее вручную размеченных TC2 примеров из книги + публичных закрытых H1 свечей с неизменным tick size; WIN/LOSS ни разу не используется как классификатор корректности.
- Закрытые H1 бар за баром, SHORT зеркальные **только для формы**, точный trigger/stop из исходного Binance OHLC.
- Отдельная матрица: WM1, WM2, WM3, plateau fractals, немедленная отмена утратившего силу pending, полноценное 1/5/4/3/2 с exchange constraints, исполненный opposite signal в прибыли **и в убытке**, duplicate prevention.
- Подписанная Binance Demo сделка LONG и SHORT, остановка приложения/потеря сети, восстановление и биржевое подтверждение STOP после исполнения и перед каждой заменой.
- Итоговый процент соответствия рассчитывать только по проверенной gold разметке; не приписывать недостающие результаты фактическим тестам.

**Статус:** source-indexed review + конкретное исправление одного доказанного TC2 противоречия; **не удостоверение 100% соответствия**.
